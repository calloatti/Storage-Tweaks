Allows changing the capacity of all storage buildings including modded ones.

Also solves the problem of pile storages drawing tall piles of items when increasing the capacity using a mod.

If you add a mod that adds storage buildings, they will be added to the config file when starting the game.

[h3]Settings:[/h3]
Settings - Mod Settings (settings are saved in \PlayerData)
